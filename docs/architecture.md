# Архитектура

Kate Fit Notes — персональный бэкенд фитнес-тренера: Telegram-бот и HTTP API
используют одну бизнес-логику и одну PostgreSQL-базу. Сайт в этот репозиторий
не входит.

## Слои приложения

```text
Telegram (bot.py) ─┐
                   ├─> сервисы ─> репозиторий ─> PostgreSQL (схема main)
FastAPI            ┘
```

| Расположение | Ответственность |
| --- | --- |
| `bot.py` | точка входа Telegram, хендлеры и проверка разрешённого `chat_id` |
| `src/Kate_Fit_Notes/bot_ui.py` | клавиатуры и тексты интерфейса бота |
| `src/Kate_Fit_Notes/session.py` | состояние сценария, изолированное по `chat_id` |
| `src/Kate_Fit_Notes/services/` | правила клиентов, записей, предоплат и отчётов |
| `src/Kate_Fit_Notes/repository.py` | параметризованные запросы к PostgreSQL |
| `src/Kate_Fit_Notes/db.py` | пул соединений PostgreSQL |
| `src/Kate_Fit_Notes/api/` | FastAPI-маршруты, JWT и HTTP-схемы |
| `src/Kate_Fit_Notes/domain.py` | чистые функции предметной области |
| `alembic/` | версия схемы базы данных |
| `tests/` | автотесты; они не используют рабочую БД |

`sql.py` сохранён как тонкий слой совместимости для прежних вызовов. Новую
бизнес-логику следует добавлять в сервис и репозиторий, а не в этот модуль.
`main.py` — заглушка IDE и не является точкой запуска. `pipelines.py` пустой
и не предназначен для новых сценариев.

## Основные сценарии

- Клиент создаётся по контакту Telegram; телефон нормализуется и хранится
  без кода страны.
- Персональная тренировка связывает клиента, тип, дату, время и при наличии
  предоплаты — конкретный пакет.
- Групповая тренировка хранит участников в `main.schedule_participant`; поле
  `schedule.client_id` для неё равно `NULL`.
- Пакет предоплаты содержит число тренировок и цену за тренировку. После
  последнего списания он помечается завершённым.
- Месячная прибыль считается как `sum(schedule.price) - sum(schedule.rent_debt)`.

## Модель данных

Все прикладные таблицы находятся в схеме `main`.

| Таблица | Назначение |
| --- | --- |
| `client` | клиенты; первичный ключ — `id`, телефон уникален |
| `trains` | типы тренировок, формат и аренда |
| `schedule` | занятие, цена, расход на аренду и связь с предоплатой |
| `schedule_participant` | участники группового занятия |
| `accounting` | пакеты предоплаты |
| `price` | история цен клиента |

Схема фиксируется миграциями Alembic. Миграции не применяются контейнерами
автоматически: это отдельная осознанная операция для конкретной базы.

## Конфигурация

Приоритет у переменных окружения; `config.ini` — только локальный fallback.
Полный перечень и безопасный шаблон находятся в [`.env.example`](../.env.example).
Пустой `TG_ALLOWED_CHAT_IDS` означает, что бот никому не отвечает.
