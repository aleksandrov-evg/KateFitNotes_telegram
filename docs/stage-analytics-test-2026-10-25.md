## Найденные и исправленные проблемы

1. Отменённая запись без связанного занятия делала неизвестными все
   посещения, загрузку и клиентские когорты. Теперь неопределённость
   локализована в количестве отмен. Финальные показатели: 2 проведённых
   занятия, 4 посещения, 3 активных клиента, 8 групповых мест, загрузка 50%.
   Эти значения независимо сверены через MCP: 4 ATTENDED записи у 3 клиентов,
   2 COMPLETED занятия с вместимостью 4 каждое.
2. CSP стенда запрещает inline style ширины столбцов: первоначально все полосы
   имели одинаковую ширину. Использован native progress с value/max и CSS
   из файла. CSP не ослаблялся. В браузере видны полная полоса поступлений
   и полоса расходов около 2,07% от неё.
3. Старые ошибки нулевой суммы оставались на экране во время корректного
   сохранения. Перед новым валидным запросом ошибки теперь очищаются.

## Ограничения

Доход по проведённым занятиям, прибыль, рентабельность и исторические денежные
балансы остаются недоступными до появления достоверных контрактов CRM.
Количество отмен не определяется для записи, у которой удалено связанное
занятие; эта проблема данных показана отдельно.

Отказы с потерей ответа, повторные клики и частичная загрузка проверялись ранее
на локальных тестовых ответах; сбои живого stage не провоцировались.
Проверка удаления ограничилась открытием подтверждения и отменой.

Локально после исправлений: 50 UI unit-тестов и 100 профильных Python
API-тестов прошли. Снимки stage сохранены в `/tmp/katfit-stage-analytics/`.
